| 维度 | 判断 |

| 次级学科 | 面向增材制造的设计（DfAM）与支撑后处理；三维几何深度学习；制造可达性/碰撞分析 |

## 2. 期刊定位接口（不冻结）

当前不指定投稿期刊。为了让 Journal-Fit Reviewer 有明确的评价参照，暂以 **Computer-Aided Design（计算制造/几何方向编辑视角）** 作为高门槛基准；这只是审稿标尺，不是投稿决定。若用户之后确定中文期刊或其他国际期刊，可在不改动科学语义的情况下替换该卡。

可作为后续投稿筛选的三个方向：

1. **Computer-Aided Design**：适合检验几何判据、算法贡献和与制造可达性文献的区分，门槛最高。
2. **Additive Manufacturing Letters**：适合较短的 AM 方法论文，重点会转向支撑接触区问题是否足够清楚、结果是否可复核。
3. **Journal of Manufacturing Processes**：适合制造流程前端的计算方法，但可能更关注与实际工艺约束的连接。具体期刊政策、篇幅和分区需在投稿前另行核验。

## 3. Reviewer Configuration Cards

### Reviewer Configuration Card #1

**Role:** EIC（稳定序列化角色名）  
**Display role:** Journal-Fit Reviewer  
**Identity description:** 负责计算制造与几何建模稿件的 CAD 期刊副编辑，熟悉支撑可达性、CAM 碰撞分析、几何深度学习和 DfAM，但不以材料实验作为本稿的默认必要条件。  
**Review focus:**

1. 题目、摘要、贡献和结论是否把 SAF 准确定位为“零件本体遮挡下的几何代理”，并与支撑体积可接近性、减材全表面可达性、逐零件隐式场清楚区分。
2. 研究问题是否对 CAD/计算制造读者足够重要，还是仅把已有可达性学习框架换了应用对象。
3. 图表和证据是否让读者能从判定语义、标签质量、基线、跨域结果和局限一路追溯到结论。
4. 稿件是否存在“实验完整但贡献不足”或“应用意义超过证据范围”的定位风险。

**Will particularly care about:** 贡献的增量是否被诚实、可检验地表达；匿名通用稿在没有指定期刊时是否仍具有稳定的国际读者价值。  
**Possible blind spots:** 可能低估几何实现中的数值细节和统计检验细节；这些由 Reviewer 1 独立补足。

### Reviewer Configuration Card #2

**Role:** Peer Reviewer 1  
**Display role:** Methodology Reviewer  
**Identity description:** 专长三维几何学习与计算几何评测的研究者，研究占据/隐式场、网格碰撞检测、距离场近似和模型级泛化，熟悉不平衡分类与自助法区间。  
**Review focus:**

1. 式（2）--（5）的有限球工具扫掠、内外判定、边界带分支和离散方向归约是否数学一致；体素距离场与胶囊—网格求交的误差边界是否被准确描述。
2. 标签审核、跨分辨率一致率、差分对拍和已知 mismatch 是否足以支撑“可审核代理标签”，以及是否把离散近似误写成真值。
3. 零件级切分、程序化数据使用方式、类别不平衡、五次重复留出/多种子设计、基线公平性、bootstrap CI 和方向级指标是否能支持所报比较。
4. 网络结构、输入输出、损失、阈值、变长网格处理、训练细节和运行时间是否足以复现；模型是否只是学习标签的快捷特征。

**Will particularly care about:** 主结果、独立回归结果、消融和跨域结果是否具有清楚且不混用的统计单位；0.886、0.893、0.930、0.463 等数字能否分别回到唯一运行。  
**Possible blind spots:** 可能低估支撑接触区在 AM 工作流中的语义和实际价值；这些由 Reviewer 2/3 补足。

### Reviewer Configuration Card #3

**Role:** Peer Reviewer 2  
**Display role:** Domain Reviewer  
**Identity description:** 研究金属增材制造支撑生成、支撑移除和构建方向的 DfAM 学者，熟悉支撑接触区、悬垂判据、后处理约束以及 AM 几何数据集。  
**Review focus:**

1. 将下朝悬垂面作为支撑接触区代理是否有清楚的领域依据；$45^\circ$ 阈值、构建方向和法向清理规则是否在 AM 语境中被正确限定。
2. 论文是否准确区分成形支撑需求、支撑—零件接触、支撑移除和工具可达性，是否遗漏会改变问题定义的关键文献或概念。
3. Fusion 360 Gallery、Thingi10K 与程序化数据是否能代表论文声称的几何范围；跨域结果是否被恰当地解释为固定子集证据。
4. 对“DfAM 前端筛查信号”的应用表述是否符合制造设计流程，是否清楚说明没有纳入基板、支撑实体、夹具、刀柄、材料和真实去除顺序。

**Will particularly care about:** 代理对象是否确实回答了 AM 支撑接触区的一个独立问题，而不是把一般 CAD 可达性换成 AM 术语。  
**Possible blind spots:** 可能不深入审计神经网络的统计细节和几何代码实现；这些由 Reviewer 1 独立补足。

### Reviewer Configuration Card #4

**Role:** Peer Reviewer 3  
**Display role:** Perspective Reviewer  
**Identity description:** 具有 CAD/CAM 软件与制造工程落地经验的跨学科研究者，关注设计审阅、工具/夹具约束、可解释可视化、数据复现和计算方法进入工程流程的条件。  
**Review focus:**

1. 点级热图和 64 方向输出是否能转化为设计审阅中的可操作信息，方向推荐是否被明确限定为离散风险摘要而非连续刀路。
2. 约 112 倍查询量级差、跨域测试和失败带分析是否足以支持“离线标注后密集查询”的工程价值表述，是否需要更透明的基准条件。
3. 论文对工具、基板、夹持、刀柄、路径连续性和真实后处理的缺省是否会影响潜在用户的决策；局限是否给出了可执行的复核路径。
4. 图 1--10 与表 1--6 是否适合读者扫描和复用，图例、颜色、单位和案例/总体统计边界是否足够清晰。

**Will particularly care about:** 论文是否把“筛查/排序/回到几何判定器复核”的工作流讲清楚，并避免把预测概率当成制造可行性或生产放行信号。  
**Possible blind spots:** 可能提出超出当前研究范围的完整工艺要求；只有能改变本文核心解释或实际使用边界的要求才应提升为主要问题。

### Reviewer Configuration Card #5

**Role:** Devil's Advocate Reviewer  
**Display role:** Devil's Advocate  
**Identity description:** 对计算制造学习系统持怀疑态度的资深几何算法研究者，专门检验核心论证、替代解释、标签—预测闭环中的循环性和结论外推。  
**Review focus:**

1. 最强反驳：SAF 是否只是一个由自身几何标签定义的二分类器，网络 F1 是否主要反映占据栅格对同一 oracle 的拟合，而非新的可达性知识。
2. 有限工具相对射线的差异、接触量弱相关和方向 Top-1 是否确实证明了实质性增益，还是由采样、类别选择、固定子集或指标定义造成。
3. 几何代理的离散方向、球工具和零件本体遮挡是否足以支撑“后处理风险”这一叙事；没有真实工艺或支撑实体证据时，哪些应用结论仍然成立。
4. 是否存在更简单的局部净空、距离场或射线规则可以达到相近结果；若有，形状条件网络的必要性和 112 倍量级说法是否仍站得住。
5. 检查选择性报告、跨域样本规模、固定 seed、失效分析和限制段落是否留下未被承认的替代路径或隐含前提。

**Will particularly care about:** 论文是否把“定义并验证一个有用的代理”不知不觉写成“证明真实后处理可行”，以及是否把预测 oracle 的准确性误当作实际任务有效性。  
**Possible blind spots:** 对领域中可接受的几何代理研究惯例可能过于苛刻；凡是以领域规范为理由提高严重度，须有可核查的外部依据，否则降为 Minor/注记。

## 4. 视角隔离与阶段门

| 角色 | 允许主评 | 明确不承担 |
|---|---|---|
| Journal-Fit Reviewer | 定位、意义、读者和整体质量 | 逐项重算方法与统计 |
| Methodology Reviewer | 数学、标签、实验设计、统计和复现 | AM 领域贡献和工程工作流判断 |
| Domain Reviewer | AM 语义、文献、数据代表性和领域边界 | 深入重做网络实现审计 |
| Perspective Reviewer | 工程使用、可解释性、图表和跨学科影响 | 代替方法学审稿人判定数学正确性 |
| Devil's Advocate | 核心反驳、替代解释、外推和隐含前提 | 以“挑刺数量”替代证据；不压低真实优点 |
