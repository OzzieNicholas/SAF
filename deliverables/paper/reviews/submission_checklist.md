# SAF 投稿接口清单

本清单承载与具体投稿目标有关、但不改变科学论证的行政信息。匿名正文、公式、表格、图和参考文献不得出现作者、单位、基金或通信方式占位符；以下项目在选择期刊后通过投稿系统和期刊模板接入。

## 当前科学稿基线

- 题型：方法与计算实验论文，研究边界为 DfAM 前端的支撑接触区几何风险代理。
- 稿件语言：中文正文，中文与英文题目、摘要和关键词。
- 匿名性：科学稿不含作者姓名、单位、基金、邮箱、致谢或可识别仓库地址。
- 正文资产：8 个编号公式、6 张表、10 幅主图、18 条已核验参考文献；表 3 还披露原始网格质量，表 5 区分完整标签源、粗几何 proxy 与学习 surrogate。
- 可复现性：`evidence/manifest.md` 提供当前冻结运行 `20260815T053210.592707Z-36276-c23969b6`、命令、样本口径、统计定义和 SHA-256 摘要；真面积与 H5 被明确标记为历史描述来源。
- 完整性：Stage 3/3' 的历史审稿材料仅说明上一版的修订轨迹，不替代本轮数值、图件和 PDF 的重新完整性核验。该状态不等于期刊录用或最终投稿授权。
- 匿名 PDF：当前输出位于 `deliverables/paper/outputs/SAF_中文论文匿名稿.pdf`；构建前须从 Zotero 重新生成 `deliverables/paper/build/references.bib`，完成 LaTeX、字体/元数据检查和逐页视觉审计后，才记录新的页数与 SHA-256。
- 数据伦理：仅使用公开三维几何与程序化数据，不涉及人或动物受试者。

## 期刊确定后接入

| 项目 | 当前处理 | 投稿前动作 | 不得影响的科学内容 |
|---|---|---|---|
| 目标期刊与栏目 | 暂不限定 | 比较主题匹配、篇幅、图表限制、匿名政策、数据政策和审稿周期后确定 | 不为迎合期刊改写冻结判定语义或夸大结论 |
| 作者名单与顺序 | 不进入匿名稿 | 全体作者确认姓名拼写、顺序和责任 | 不改实验归属与证据记录 |
| 作者单位 | 不进入匿名稿 | 按期刊格式录入完整中英文单位和地址 | 不写入双盲文件元数据 |
| 通信作者 | 不进入匿名稿 | 确认通信人、邮箱与 ORCID | 不写入匿名 PDF |
| 基金与项目号 | 不进入匿名稿 | 按真实资助文件逐项录入；无资助则按期刊规定声明 | 不推测或生成基金号 |
| CRediT 作者贡献 | 不进入匿名稿 | 由全体作者确认角色 | 不由模型替作者分配贡献 |
| 利益冲突 | 不进入匿名稿 | 每位作者完成真实声明 | 未确认前不写“无冲突” |
| 数据与代码地址 | 匿名稿只给证据清单 | 确定匿名仓库、永久 DOI 或录用后公开策略，并核对数据许可 | 不虚构公开 URL 或 DOI |
| AI 使用声明 | 不进入通用科学正文 | 查询目标期刊政策，如实描述辅助范围并由作者确认 | 不声称 AI 对研究内容承担作者责任 |
| 致谢 | 不进入匿名稿 | 去匿名后加入真实技术和数据协助 | 不泄露匿名身份 |

## 选刊时的质量优先级

1. 期刊范围应同时容纳计算几何、增材制造设计与机器学习代理模型，而非要求材料、金相或实体工艺实验作为基本门槛。
2. 审稿人应能接受“几何代理评价”作为明确研究对象；若期刊默认把可达性等同于完整工艺可行性，需在投稿信中主动界定范围。
3. 优先选择允许公开数据、计算实验和补充材料的期刊，以便提交证据清单、运行产物和高分辨率图件。
4. 版面应容纳至少 6 张表和 10 幅图，或允许把部分审核图移入补充材料；不因图数限制删除标签质量、基线或失败分析证据。
5. 在期刊确定前保持通用双栏稿，不预先添加期刊徽标、卷期、收稿日期、分类号或虚构模板字段。

## 投稿前机械检查

- [ ] 将通用 `ctexart` 外壳映射到目标期刊官方模板，逐项核对字号、栏宽、图表位置和参考文献样式。
- [ ] 检查匿名 PDF 的文档属性、嵌入字体、图片元数据、文件路径、Git 链接和致谢信息。
- [ ] 按目标期刊要求决定图注是否中英双语；不在图中嵌入正文式说明。
- [ ] 核对摘要字数、关键词数量、正文页数、图表上限和补充材料格式。
- [ ] 重新解析全部 DOI；特别复核名义出版月为 2026-09 的 Computer-Aided Design 卷 198 条目是否已有最终书目信息。
- [ ] 全体作者审核题目、摘要、贡献边界、局限、数据声明和投稿信。
- [ ] 由通信作者完成基金、利益冲突、作者贡献、数据许可和 AI 使用声明。
- [ ] 运行文稿 QA、图件 QA、完整测试和验收门，并将已知的非科学治理阻塞与论文证据问题分开报告。

## 投稿材料接口

| 材料 | 来源 | 说明 |
|---|---|---|
| 匿名正文 PDF | `outputs/SAF_中文论文匿名稿.pdf` | 本轮通用双栏科学稿；选刊后再套模板，须以本轮 PDF QA 结果为准 |
| Markdown 主稿 | `manuscript/paper.md` | 内容单一源稿 |
| 表格母稿 | `manuscript/tables.md` | 六张表及统计口径 |
| 图件 | `figures/fig01_*.{png,pdf}` 至 `figures/fig10_*.{png,pdf}` | 600 dpi PNG 与矢量 PDF 成对提交 |
| 图注母稿 | `manuscript/captions.md` | 中英双语候选，可按期刊要求裁剪 |
| 参考文献 | `build/references.bib` | 由 Zotero 临时导出的 18 条书目，不进入 Git |
| 引文审计 | `manuscript/reference_audit.md` | 逐条用途、来源与受限页面记录 |
| 证据清单 | `evidence/manifest.md` | 量化结论到运行产物的映射 |
| 完整性报告 | `evidence/integrity_report.md` | 图文/数值一致性检查、外部核验和发布阻塞的状态记录 |
| 完整性 sidecar | `evidence/integrity_sidecar.json` | 图表 trace、实验 provenance 与主张对齐结果 |
| 修订后再审 | `reviews/stage3/re_review_stage3_prime.md` | R1--R7 逐项验证、残余限制与 Stage 3' 裁决 |

本清单中的未定项目不构成科学稿阻塞；只有在具体期刊、作者团队和真实行政信息确定后，才进入相应投稿字段。
