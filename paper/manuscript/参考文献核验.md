# 参考文献核验记录

适用文稿：`paper/manuscript/论文正文.md`；规范书目：`paper/manuscript/references.bib`。

## 1. 核验范围与方法

- 范围：18 条书目的存在性与字段准确性；15 个实质性引用簇的语境支持；正文与书目的双向映射。
- 存在性：DOI 以 Crossref 注册元数据核对；arXiv 条目以 arXiv 官方记录核对。
- 字段：逐项核对题名、完整作者、载体、年份、卷期、页码或文章号、DOI 或稳定标识。
- 受限页面：出版社页面受验证码、超时或反自动化策略限制时，不把“页面未打开”记为“书目不存在”，也不声称读取了受阻全文。
- 语境：正文主张必须落在来源题名、摘要、官方页面或可访问预印本实际覆盖的范围内；题名相似不构成语义支持。
- 隐私：Crossref 查询只发送公开 DOI，不发送稿件正文、实验数据或私有文件。
- 限制：未使用 Semantic Scholar 等聚合接口作为裁决依据；未借助外部模型做交叉核验，也未向外部服务发送稿件内容。核验不能替代作者对每篇原文的最终人工复核。

## 4. 双向一致性

- 正文使用 18 个唯一文献编号，LaTeX 使用同一组 18 个 BibTeX 键；`references.bib` 恰有 18 个条目。
- 18 条书目均在正文中至少有一个实质性语境引用；不存在只进书目、不进正文的条目。
- 正文不存在指向缺失书目的编号或键；LaTeX 编译无 undefined citation。
- 正文与书目中不含 `TBD`、`TODO`、`待补`、`unknown`、虚构 URL 或 DOI，也不以 `et al.` 代替完整作者字段。
- 中文 Markdown 参考文献顺序与 LaTeX 的 GB/T 7714 数字顺序一致。

## 6. 结论与限制

18/18 条参考文献存在性为 VERIFIED，字段一致；15/15 个实质性引用簇均得到来源支持，其中 B11 的主张已限定在来源覆盖范围内。未发现伪造、错配、拼接书目、ghost citation，或正文主张超出来源范围的问题。

限制：页面受限的来源未作为已读全文；Semantic Scholar 等聚合接口未作为裁决依据；投稿前仍需作者对每篇原文做最终人工复核。
