# SAF 投稿接口清单

本清单承载与具体投稿目标有关、但不改变科学论证的行政信息。匿名正文、公式、表格、图和参考文献不得出现作者、单位、基金或通信方式占位符；以下项目在选择期刊后通过投稿系统和期刊模板接入。

## 当前科学稿基线

- 题型：方法与计算实验论文，研究边界为 DfAM 前端的支撑接触区几何风险代理。
- 稿件语言：中文正文，中文与英文题目、摘要和关键词。
- 匿名性：科学稿不含作者姓名、单位、基金、邮箱、致谢或可识别仓库地址。
- 正文资产：7 个编号公式、4 张表、10 幅主图、20 条已核验参考文献（含 5 条中文文献）；表 2 披露原始网格质量，表 4 区分固定留出集、全部未见零件、跨来源（含扩大训练规模的对照）与重复随机留出四种测试范围。
- 目标期刊候选：《计算机辅助设计与图形学学报》（CAD/CAE/CAM 栏目）。该刊要求中文摘要 200–300 字、英文摘要 100–150 个实词，并要求提交 AIGC 使用声明（模板见期刊官网「投稿必读｜投稿模板」）。
- 可复现性：`evidence/证据清单.md` 说明冻结的实验、命令、样本口径和统计定义，`evidence/manifest.json` 记录每个结果文件的哈希；正文数值由 `manuscript/numeric_claims.yaml` 逐条核对。
- 完整性：改动数值、图件或证据后，运行 `python -m paper.pipeline.build_paper` 重新冻结证据并通过源稿审计与论文门。该状态不等于期刊录用或最终投稿授权。
- 匿名 PDF：`paper/outputs/SAF_中文论文匿名稿.pdf`，由 `python -m paper.pipeline.build_paper` 生成（不入库）。投稿前还需做 LaTeX 字体与元数据检查，以及逐页视觉审计。
- 数据伦理：仅使用公开三维几何与程序化数据，不涉及人或动物受试者。

## 期刊确定后接入

| 项目 | 当前处理 | 投稿前动作 | 不得影响的科学内容 |
|---|---|---|---|
| 目标期刊与栏目 | 暂不限定 | 比较主题匹配、篇幅、图表限制、匿名政策、数据政策和审稿周期后确定 | 不为迎合期刊改写冻结判定语义或夸大结论 |
| 作者名单与顺序 | 不进入匿名稿 | 全体作者确认姓名拼写、顺序和责任 | 不改实验归属与证据记录 |
| 作者单位 | 不进入匿名稿 | 按期刊格式录入完整中英文单位和地址 | 不写入双盲文件元数据 |
| 通信作者 | 不进入匿名稿 | 确认通信人、邮箱与 ORCID | 不写入匿名 PDF |
| 基金与项目号 | 不进入匿名稿 | 按真实资助文件逐项录入；无资助则按期刊规定声明 | 不推测或生成基金号 |
| CRediT 作者贡献 | 不进入匿名稿 | 由全体作者确认角色 | 不由模型替作者分配贡献 |
| 利益冲突 | 不进入匿名稿 | 每位作者完成真实声明 | 未确认前不写“无冲突” |
| 数据与代码地址 | 匿名稿只给证据清单 | 确定匿名仓库、永久 DOI 或录用后公开策略，并核对数据许可 | 不虚构公开 URL 或 DOI |
| AI 使用声明 | 不进入通用科学正文 | 《计算机辅助设计与图形学学报》要求披露使用者、系统与版本、使用时间、提示、由 AIGC 编写或共同编写的部分以及因此产生的想法，并提交声明扫描件；如实描述正文、图件脚本与实验脚本中的辅助范围，由作者确认 | 不声称 AI 对研究内容承担作者责任 |
| 致谢 | 不进入匿名稿 | 去匿名后加入真实技术和数据协助 | 不泄露匿名身份 |

## 选刊时的质量优先级

1. 期刊范围应同时容纳计算几何、增材制造设计与机器学习代理模型，而非要求材料、金相或实体工艺实验作为基本门槛。
2. 审稿人应能接受“几何代理评价”作为明确研究对象；若期刊默认把可达性等同于完整工艺可行性，需在投稿信中主动界定范围。
3. 优先选择允许公开数据、计算实验和补充材料的期刊，以便提交证据清单、运行产物和高分辨率图件。
4. 版面应容纳 4 张表和 10 幅图，或允许把部分审核图移入补充材料；不因图数限制删除标签质量、基线或失败分析证据。
5. 在期刊确定前保持通用双栏稿，不预先添加期刊徽标、卷期、收稿日期、分类号或虚构模板字段。

## 投稿前机械检查

- [ ] 将通用 `ctexart` 外壳映射到目标期刊官方模板，逐项核对字号、栏宽、图表位置和参考文献样式。
- [ ] 检查匿名 PDF 的文档属性、嵌入字体、图片元数据、文件路径、Git 链接和致谢信息。
- [ ] 按目标期刊要求决定图注是否中英双语；不在图中嵌入正文式说明。
- [ ] 核对摘要字数、关键词数量、正文页数、图表上限和补充材料格式。
- [ ] 重新解析全部 DOI；复核 `dutta2026implicit` 的卷期与页码是否与最终出版版本一致。
- [ ] 全体作者审核题目、摘要、贡献边界、局限、数据声明和投稿信。
- [ ] 由通信作者完成基金、利益冲突、作者贡献、数据许可和 AI 使用声明。
- [ ] 运行文稿 QA、图件 QA、完整测试和验收门，并将已知的非科学治理阻塞与论文证据问题分开报告。

## 投稿材料接口

| 材料 | 来源 | 说明 |
|---|---|---|
| 匿名正文 PDF | `outputs/SAF_中文论文匿名稿.pdf` | 通用双栏科学稿，由 `python -m paper.pipeline.build_paper` 生成（不入库）；选刊后再套模板 |
| Markdown 主稿 | `manuscript/论文正文.md` | 内容单一源稿，含四张表、公式、图注和参考文献列表 |
| 图件 | `figures/` 下十幅主图，每幅一对同名 PNG 与 PDF（名单见 `paper/pipeline/figure_scripts/__init__.py`） | 600 dpi PNG 与矢量 PDF 成对提交 |
| 参考文献 | `manuscript/references.bib` | 20 条书目，条目顺序即正文编号 |
| 引文审计 | `manuscript/参考文献核验.md` | 逐条用途、来源与受限页面记录 |
| 数值声明表 | `manuscript/numeric_claims.yaml` | 正文数值到实验结果的逐条登记 |
| 证据清单 | `evidence/证据清单.md`、`evidence/manifest.json` | 量化结论到运行产物的映射与哈希 |

本清单中的未定项目不构成科学稿阻塞；只有在具体期刊、作者团队和真实行政信息确定后，才进入相应投稿字段。
