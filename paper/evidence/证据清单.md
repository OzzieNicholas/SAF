# 论文证据清单

机器可读的证据清单是 [manifest.json](manifest.json)：它冻结论文用到的每个实验结果文件的相对路径、SHA-256 和运行标识，由 `python -m paper.pipeline.audits.freeze_evidence` 从 `artifacts/runs/` 生成。本文件解释这些证据支撑什么、统计单位是什么、哪些结论不能由它们推出。正文数字与证据的逐条核对见 [numeric_claims.yaml](../manuscript/numeric_claims.yaml)，由 `python -m paper.pipeline.audits.check_manuscript` 执行。

## 1 研究边界

论文所有标签和预测使用同一冻结语义：潜在支撑接触区代理、仅零件本体遮挡、半径 `r=0.05` 的球工具、128 个全局 Fibonacci 候选方向及其 64 个下半球方向、离散直线逼近。网络不接收半径、构建方向或方向向量作为条件。论文不建模基板、支撑之间遮挡、刀柄、夹具、连续工具路径、真实去支撑或工艺认证，也不做构建方向优化。

几何证据层级固定为：完整 128 全局 / 64 下半球方向的细化几何 oracle 只供应离线标签；16 全局 / 8 下半球方向的有限工具结果是粗几何代理；神经网络是形状条件 surrogate。三者不能互换为彼此的「真值」或「竞争 oracle」。

## 2 实验与证据

下表每行对应 manifest 中的一个实验键，结果文件为 `artifacts/runs/<实验名>/result.json`；复现命令和数值见 [结果账本](../../governance/结果账本.md)。

| 实验 | 样本与统计单位 | 支撑的论文内容 |
|---|---|---|
| `support_area_vs_accessibility` | Fusion 全量 8,590 件；两类件 1,553 件；零件为单位 | 支撑面积（计数代理）与不可达比例弱相关（图 6、5.2 节） |
| `true_triangle_area_check` | 同上，改用真实三角面积 | 面积口径不是代理造成的假象（5.2 节） |
| `tool_radius_effect` | Fusion 600 件、程序化 120 件的接触点 | 射线可见但有限工具不可达的点占比（5.2 节） |
| `label_audit` | 160 个差分采样点；10 件分辨率对比；Fusion 全量分布 | 标签质量审核（表 4） |
| `oracle_differential_audit` | 10,000 件固定种子程序化案例 | 快速判定器与精确参考的对拍（表 4） |
| `mesh_quality_audit` | Fusion、Thingi10K 全部物化件与两类件 | 原始网格质量披露（表 3） |
| `cross_model_prediction` | Fusion 两类件 1,553 件，程序化 120 件辅助训练；5 次 0.6/0.2/0.2 留出，每次测试 310 件，测试集可重叠 | 点级主结果与零件分布（摘要、5.3 节） |
| `baseline_comparison` | Fusion 前 400 件两类件；80 件留出、6,033 点；单种子 | 六方法基线与逐件配对差（表 5、图 8 左） |
| `regression_check` | 同一 80 件留出集；独立训练；2,000 次配对 bootstrap | 独立回归复核，不与基线点估计合并 |
| `shape_context_ablation` | 同一 400 件子集；单种子、60 轮 | 形状上下文消融（图 8 右）；只比较变体相对趋势 |
| `failure_analysis` | 同一 80 件、6,033 点；5 个训练种子 | 误判按可达方向数分箱（图 10、5.5 节） |
| `cross_domain_robustness` | Fusion 留出与 Thingi10K 137 件两类件；3 个训练种子 | 跨域结果（表 6 上半） |
| `direction_field_prediction` | Fusion 前 500 件；3 个 70/30 模型级种子；64 个方向；每次测试 150 件 | 方向级场结果（图 9、表 6） |
| `direction_field_audit` | 同一 cohort 的 seed 0 切分 | 方向分母审计与随机、全局先验排序基线（表 6） |
| `inference_speed` | Fusion 30 件、1,323 点 | 单点摊销查询量级（5.5 节） |

`baseline_comparison` 与 `regression_check` 是独立的训练和评测进程，同一配置的 GPU 训练存在运行间波动；前者用于六方法同集比较，后者用于独立回归复核，两者不能拼成同一个「最终准确率」。

## 4 统计与限制

- 不可达 / 被挡是 F1 正类。点池 F1、零件等权 F1、零件内分布、训练种子间标准差分别报告，不混读。
- 点级主结果的五次随机留出测试集可以重叠，不能称为 K 折交叉验证。
- Top-k 只在至少存在一个几何可达方向的 eligible 点上定义。网络三种子均值与 seed 0 的随机 / 先验基线只作描述性比较，不作配对显著性推断。
- 网格审计描述被数据清单保留的源网格；不证明未审计外部网格、真实支撑实体或实际后处理可行性。
- 查询时间倍数是当前实现与硬件上的单点摊销量级，不包括端到端预处理、模型加载或制造过程，不能视为普遍速度承诺。
