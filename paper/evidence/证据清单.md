# 论文证据清单

机器可读的证据清单是 [manifest.json](manifest.json)：它冻结论文用到的每个实验结果文件的相对路径、SHA-256 和运行标识，由 `python -m paper.pipeline.audits.freeze_evidence` 从 `artifacts/runs/` 生成。本文件解释这些证据支撑什么、统计单位是什么、哪些结论不能由它们推出。正文数字与证据的逐条核对见 [numeric_claims.yaml](../manuscript/numeric_claims.yaml)，由 `python -m paper.pipeline.audits.check_manuscript` 执行。

## 1 研究边界

论文所有标签和预测使用同一冻结语义：以下朝悬垂面为支撑接触区代理、仅零件本体遮挡、半径 `r=0.05` 的球工具、128 个全局 Fibonacci 候选方向及其 64 个下半球方向、离散直线逼近，边界带内以胶囊—网格精确求交。网络不接收半径、构建方向或方向向量作为条件。论文不建模基板、支撑之间遮挡、刀柄、夹具、连续工具路径、真实去支撑或工艺认证；方向评价只比较给定候选方向，不做构建方向优化。

两级几何判定器只供应标签；不经细化的体素判定（含 16 方向粗判定）与零半径射线是几何代理；网络是学习代理。三者不能互换为彼此的「真值」。

## 4 统计与限制

- 不可达 / 被挡是 F1 正类。点池 F1、零件等权 F1、训练种子间标准差分别报告，不混读。
- 固定留出集的数值偏乐观；更一般的表现以全部未见零件上的结果为准。
- 重复随机留出的测试集可以重叠，不能称为 K 折交叉验证。
- Top-k 只在至少存在一个几何可达方向的点上定义；网络三种子均值与 seed 0 的随机 / 先验基线只作描述性比较。
- 方向评价把零件刚体旋转到 6 个轴向，只比较这些候选方向，不搜索连续方向空间。
- 耗时比较含 Python 实现与硬件因素，只说明量级。
