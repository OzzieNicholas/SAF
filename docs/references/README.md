# 文献资料

本目录是 SAF 的只读研究输入区，不是活动治理入口，也不是论文交付物。

- `literature/` 保存已收集的论文 PDF；它们是研究输入，不作为运行时依赖。
- `references_cn.md` 保存中文文献候选及核验备注。
- 文献矩阵和问题关联以 `../2_文献矩阵与相关工作.md` 为富参考，以 `../../governance/evidence.md` 为活动治理摘要。
- 论文最终引用以 `../../deliverables/paper/latex/references.bib` 为装配来源。

新增文献应先进入这里，并在文献矩阵或治理证据中建立指针；不得重新放入 `deliverables/paper/`。
