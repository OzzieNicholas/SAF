# 文献资料

本目录是 SAF 的只读研究输入区，不是活动治理入口，也不是论文交付物。

- `literature/` 只保留 Zotero 迁移说明；论文 PDF 统一由 Zotero 集合“几何可达与神经预测”（F5ITM9M6）管理，不再进入 SAF。
- `references_cn.md` 保存中文文献候选及核验备注。
- 文献矩阵和问题关联以 `../2_文献矩阵与相关工作.md` 为富参考，以 `../../governance/evidence.md` 为活动治理摘要。
- 论文构建时从 Zotero 生成临时 `deliverables/paper/build/references.bib`，不进入 Git。

新增文献应先进入 Zotero 集合，并在文献矩阵或治理证据中建立指针；不得把 PDF 重新放入 SAF。
