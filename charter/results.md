## 局限（论文诚实局限，均有据）

- **代理非认证**：oracle 是几何可达性代理（语义 C），非物理/工艺认证；遮挡下界（只计零件本体，D-002）。
- **标签噪声**：真实标签差分 robust 不一致 **0.63%**、res48↔96 稳定 **97.28%**（~2.7% 点跨分辨率翻）——已量化（D-025），非零。
- **类别不平衡**：Fusion **82% 件全可达 / 仅 18% 两类件**（1553/8590）；不可达是稀有类（占比 5.1%）。
- **H1 面积口径**：'支撑面积'实为**下朝面计数代理**（非真三角面积；面积均匀采样未实现，见 conf/params.yaml sampling 注 / D-028）。离线真面积对照（1500 件、**旧口径**标签）：真面积 ρ=**0.16**(全)/**0.11**(两类) **< 计数代理 0.27/0.26**——**H1"面积弱预测可达"在真面积下更成立、非代理伪影**；面积加权指标属未来工作。
- **D-028 口径（已切换）**：`fusion360_full` 及上表全部数字已按 **D-028 新网格前端口径**重物化 + 命门重签收——缠绕安全外移三态弃 **11,573** 翻面伪下朝面点（旧 2.42%），both-class 1621→**1553**；thingi 弃 **4,321** 点、149→**137**；procedural 不受影响。相对旧口径 headline 主变化：**H3 0.910→0.882**（弃伪易样本后的诚实值），余稳（H1/H2/E5/E8/消融/H5 定性不变）。旧口径数字见 git 历史。
- **数据代表性**：Fusion 棱柱几何为主、无自由曲面；8625 设计中成功物化 8590 件。
- **跨域子采样**：Thingi 每件 max_points=400 + max_faces=80000（D-022）——跨域指标是子采样无偏估计。
- **E5 口径**：方向标签用**占据口径**（无 D-020 细化）；方向级标签若作 headline 训练源，**尚待作者签收**（D-024）。
- **辅助信号口径**：程序化 procedural_v1 用 **n_dir=32**（受控已知答案辅助信号，粗口径、略偏保守），与 Fusion 训练件的冻结 128 口径不同；混入训练（ftr+proc），但**所有 headline 指标皆在 128 口径的 Fusion/Thingi 测试集评估**，故影响有界。
- **H4 应用价值 / E8 效率**：仅覆盖推理效率（E8）+ 方向场（E5）；半径扫描 / 工具条件插值属未来工作（docs/3 §14.3），非本工程。E8 的 ~112× 按 **docs/3 §9.6 收窄**为**训练后条件扫掠摊销的量级示意**——"神经比逐点几何快"本身非本文新发现，且比值含实现因素（oracle 侧为逐点 Python 循环）。
