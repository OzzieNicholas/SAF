# 研发路线

研发阶段的划分，以及每个阶段的产出放在哪里。本文件只写结构，不写进度和数值：

- 现状（哪些门绿、哪些待办）→ 运行 `python tests/gate.py --format md`。
- 数值与复现命令 → [结果账本](结果账本.md)。
- 冻结的判定语义和口径 → [决策台账](决策台账.md)。

阶段号（0–10）和假设号（H1–H5）是逻辑标签，只用在决策台账和结果账本里，不作文件名。

## 阶段划分

| 阶段 | 目标 | 产出位置 |
|---|---|---|
| 0 问题契约 | 冻结问题定义、边界和铁律 | [问题定义](问题定义.md)、[铁律约束](铁律约束.md) |
| 1 判定语义 | 语义 C、基板不建模、体素腐蚀、二分类、球模型 | 决策台账 D-001 至 D-005 |
| 2 文献与设计 | 梳理相关工作，确定空白，推演数据、标签、模型和指标 | [文献证据](文献证据.md)、[文献矩阵](../docs/文献矩阵与相关工作.md)、[研究背景与设计](../docs/研究背景与设计.md) |
| 3 数据 | 程序化件、Fusion360 主数据集、Thingi10K 跨域测试集 | `src/support_accessibility/data/`、`tools/build_*_dataset.py` |
| 4 几何 oracle 与标签质量 | 精确细化、缠绕安全外移、标签量化审核 | `src/support_accessibility/oracle/`、`experiments/label_audit.py` |
| 5 基线与指标 | 几何基线、指标、预算门与回归门 | `src/support_accessibility/{baselines,eval}/`、`experiments/regression_check.py` |
| 6 神经预测 | ConvONet-lite 跨模型预测与形状上下文消融 | `src/support_accessibility/models/`、`experiments/cross_model_prediction.py`、`experiments/shape_context_ablation.py` |
| 7 完整实验 | 跨域鲁棒性、方向级场、旗舰对、查询效率 | `experiments/` |
| 8 可视化与失败案例 | 审计图、误判刻画 | `src/support_accessibility/viz/`、`experiments/failure_analysis.py` |
| 9 论文 | 正文与实验并行，数字对齐结果账本 | `paper/` |
| 10 投稿与修改 | 期刊选定后的行政接入与修订 | `paper/投稿清单.md` |

## 主线

主线是 oracle 真值加形状条件神经跨模型预测，几何启发式作为对照基线（D-015）。

## 后续方向

- 方向级场扩量到全量 Fusion 数据；细化口径的方向标签作为头号训练源前，须作者据实签收（D-024）。
- 半径扫描与工具条件插值（当前网络不以半径或方向为条件）。
- 面积加权的指标（当前「支撑面积」是接触点计数代理）。
