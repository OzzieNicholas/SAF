# 问题定义

更详细的背景和设计推演见 [研究背景与设计](../docs/研究背景与设计.md)。判定语义与冻结决定见 [决策台账](决策台账.md)，文献关系见 [文献证据](文献证据.md)，铁律见 [铁律约束](铁律约束.md)。

## 目标

在单个公开三维零件上，识别由构建方向 d 决定的支撑接触区（下朝悬垂面代理），评价这些**表面区域**在简化工具条件下的几何可接近性，并用形状条件神经网络在**未见零件**上预测该可达性，为 DfAM 预处理提供不同于支撑体积、悬垂面积的后处理几何风险维度。

## 硬约束

不可违反，另见 [铁律约束](铁律约束.md)。

- 落在几何、算法、AI 一侧：正确性用几何推理、程序化构造和公开数据复现来验证，不依赖材料或工艺的物理实验。
- 单卡可完成（RTX 4060 / 32G）：中小规模网络、数据和训练时长。
- 只用公开数据（Fusion360 [R20]、Thingi10K [R19]）和程序化模型；ABC 已弃用（D-023）。与企业项目的隔离体现在输入、输出、目标、数据、评价五个维度全部不同。
- 贡献写成“定义问题 + 采用成熟方法”；跨模型预测是采用而非首创（DeepMill [R6] 在先）；哈希编码只是效率模块，不是主创新。

## 非目标

多零件排布、防互锁、刚体可分离性认证；真实打印、真实拆支撑、材料、热、残余应力、显微组织；完整支撑生成；工具路径、夹具、机器人运动规划；构建方向优化算法；网格简化。

## 指标

按零件切分，以零件为统计单位为主；冻结口径见 [oracle_params.yaml](../configs/oracle_params.yaml)，守护性质在 `tests/acceptance/`。

| 层级 | 指标 |
|---|---|
| 主指标 | 不可达类 F1；不可达区域 IoU；不可达**点占比**误差；方向排序 Top-k 命中率与 precision@k（方向级场）；支撑面积（下朝面计数代理，D-028）与不可达比例的 Spearman 相关；单零件热图生成时间；Fusion360 到 Thingi10K 的跨域下降 |
| 辅助指标 | Accuracy、AUROC、PR-AUC |

不可达是风险正类，重点报告它的 recall 和 F1：漏报不可达比误报更严重。

## 样例

| 类别 | 内容 |
|---|---|
| 代表 | 开阔外表面的下朝面（应可达）；深窄槽底、盲腔内下表面（应不可达） |
| 压力 | 极深盲孔；开口很窄但射线可见的槽；薄壁法向不稳；自相交；支撑接触区极小；大面积开放下表面；多连通分量 |
| 失败 | 可达与不可达的边界带；坏网格；深腔全局遮挡不足 |
| 旗舰配对 | 成对构造：支撑面积近似相等、腔深或开口不同的两个方向或零件（`data.procedural.flagship_pair`） |
