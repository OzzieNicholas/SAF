# 铁律约束

本课题不可协商的铁律，在任何设计和实现之前锁死，全程不得违反。只放真正不可动的内容；可变的偏好和数值进 `configs/oracle_params.yaml` 或决策台账。

1. **几何代理，非生产认证。** 全程表述为"支撑接触区几何可达性代理评价 / DfAM 前端风险提示"，不承诺真实支撑一定可拆、不做完整生产可行性认证。

2. **企业隔离五维。** 输入/输出/目标/数据/评价全部不同于企业项目。禁止：多零件排布、固定姿态共基面业务规则、三维交错布局、防互锁、刚体可分离性认证、取件顺序；禁用企业零件/参数/样例/验收逻辑/代码/内部术语（打印排布包络、静态正间距、可分离性三态等）。

3. **贡献定位。** 写"定义问题 + 采用成熟方法"，不写"提出新方法/首创"。跨模型预测=采用（DeepMill 在先）；哈希编码=效率模块，不入标题、不作主贡献。绝不把方向级评价写成"构建方向优化算法"。

4. **oracle 判定口径不可私改。** 语义 C（D-001）+ 基板不建模/下半球/只计本体遮挡（D-002）+ 体素腐蚀口径（D-003）是判定语义的一部分，属论文正文。任何改动必须在 `决策台账.md` 新增条目 supersede，不得在实现里悄悄改。

5. **只在公开/程序化数据上工作。** Fusion360 Gallery[R20] + Thingi10K[R19] + 程序化模型（ABC 已弃用，D-023）；不依赖材料/工艺物理实验、真实打印、材料检测或企业数据。

6. **标签先于模型。** oracle 与标签未通过质量门（六项趋势审核）之前，不进入正式神经实验（对应“建门先于建码”）。

7. **命门人签收，自动化不得关命门。** 命门 = 判定语义（D-001..）、真实网格标签质量、企业隔离与不过度声称的边界纪律。自动化（含 agent 循环）只在独立可信门（构造即知答案、差分对拍等，真值不依赖被测物）下迭代到绿；命门须作者据实**签收**——无导师/合作者时，以**量化标签审核**（`experiments/label_audit.py`：差分 robust / res-稳定 / 分布，客观可复现）+ 机器可判趋势门证据替代外部评审（作者一次性认可审核阈值，逐集由量化裁定，非人工视觉审图）。未过审核的真实网格标签不进训练集（铁律 #6 的落地）。见决策台账 D-018（证据机制经 **D-025** 客观化）。
