# evidence — 文献证据

> 治理 · 证据层（散文，薄）。规则：只写"**来源 → 对本问题意味着什么 / 它的边界或不成立处**"，不是读书笔记。
> 富矩阵、逐篇辨析、Related Work 骨架、全局登记表留在 `docs/2_文献矩阵与相关工作.md`（退役参考，[R1]–[R27] 编号以其为准）；文献附件由 Zotero 集合管理，`docs/references/` 只保留入口和候选书目。

## 问题正当性（支撑接触区值得研究）

- **[R1] Jiang 支撑综述(2018)** → 支撑带来材料/时间/能耗/后处理成本，金属支撑移除受**工具可达性**限制 ⇒ 问题正当、非造词。边界：综述，无神经预测、无可达性场。
- **[R2] Nelaturi 自动支撑移除(2019)** → 把"支撑与零件的**接触区域**"作为后处理对象，避碰安排移除 ⇒ 支撑接触区是公开研究的关键几何对象。边界：含移除顺序/姿态/运动规划（本文不做）。

## 最直接前身：IMF / 支撑可去除性（体 vs 面）

- **[R3][R4] Mirzendehdel IMF(2021/2022)** → 可达性可表达为连续空间场（不可接近支撑体积、IMF）用于构建方向与拓扑优化 ⇒ "可达性场化"的合法来源。边界：对象是支撑**体积**、绑多轴减材铣削。**本文差异 = 面（表面区域）vs 体、一般后处理 vs 多轴铣。**

## 神经近邻（方法同源，必须正面处理）

- **[R6] DeepMill(2025, TOG)** → 神经可达性、跨模型免重训、工具尺寸条件、CAD+自由曲面、实时密集热图、遮挡单独识别**均已实现**（减材全表面）⇒ 这些**不是本文方法创新**；语义 C 的不可达定义即来自它。**本文差异 = 对象（AM 支撑接触区表面）+ AM 后处理语义（"事后难清理"），方向语义（单一构建方向决定分布）。本文不声称超越。**
- **[R7] PARC(2024)** → 可达性/碰撞测度可用神经隐式场表示，但偏**逐零件配置空间场、需 per-shape 重训** ⇒ **跨模型预测是本文相对 PARC 的关键区分点**；警惕：若最终只做逐零件拟合会接近 PARC。
- **[R5] Surfel CNN 支撑检测(2019)** → AM 支撑的神经先例，但做的是**支撑检测（哪里要支撑）** ⇒ 本文落点前移到"支撑区的**后处理可达性**"，二者是链条上不同环节。

## 方法范式（采用，非贡献）

- **[R8][R9] DeepSDF / OccNet** → 连续可查询神经场适合表达三维几何属性（采用范式，非首创）。
- **[R10] ConvONet** → 卷积编码器带来局部特征与**跨模型泛化** ⇒ "形状条件"的关键依据。
- **[R11] Instant-NGP** → 哈希编码提升效率，但裸哈希≠跨模型泛化 ⇒ 只作局部高频/逐零件细化的效率模块，不入标题不作主贡献。

## 跨域旁证 / 趋势（不喧宾夺主）

- **[R13][R14][R15] 机器人 CDF / Neural Fields 综述 / CSSDF-Net** → "距离/碰撞/安全/可达性场化并神经化"是跨领域趋势 ⇒ 侧面支撑方法合理性；本文不研究机器人运动学/路径规划。
- **[R16][R17] INF-3DP / 隐式制造过程规划(2025)** → 神经隐式场进入多轴打印/制造规划 ⇒ 趋势补充；对象是路径/运动，非 LPBF 支撑接触区可达性。

## 数据

- **[R20] Fusion 360 Gallery reconstruction（主 CAD 网格源，D-017）** → 8,625 个 sketch+extrude 干净 CAD 实体，只用其 .obj 三角网格（**不用**构造序列/B-Rep，故非 CAD 序列建模）；拉伸挖出的凹槽/盲孔/通孔提供受限可达性特征。边界：棱柱几何为主、无自由曲面（下朝面多为平面+凹槽天花板），须在论文数据代表性段写明；可能多体（筛单体或堆叠占据）。
- **[R18] ABC（已弃用，D-023；D-017 前为主源）** → 机械 CAD 来源；因下载不便，主 CAD 源角色由 Fusion360[R20] 取代，现彻底不采用、不接入。可控变量由程序化模型补（见 R20/R19）。
- **[R19] Thingi10K** → 真实打印网格，测跨域鲁棒性（非流形/自交/三角汤）。边界：类别杂、非工业金属件 ⇒ 作测试/鲁棒性，不作主训练。
