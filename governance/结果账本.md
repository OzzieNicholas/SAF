# 结果账本

「假设 / 实验 → 指标 → 数值 → 样本」的唯一出处，权威数字以此为准。数值由 `experiments/` 下的脚本产出，运行记录保存在 `artifacts/runs/<实验名>/result.json`（含提交号与输入摘要）；规范参数只在 `tools/reproduce_experiments.py` 登记，`python tools/reproduce_experiments.py --only <实验名>` 即可复现单项。论文引用的数字另由 `paper/manuscript/numeric_claims.yaml` 与这些结果逐条核对。

- 假设编号 H1–H5 的含义见 [研究背景与设计](../docs/研究背景与设计.md) §6.1；其余实验直接用名称。
- 冻结口径见 D-021（128 个全局方向等）；数据集按 D-028 的网格前端口径物化。
- 评测协议见 D-034：点级网络只按固定留出协议（Fusion 前 400 件两类件、切分种子 0、0.6/0.2/0.2，训练集加程序化件）以 5 个训练种子训练一次，表中标注「同一组模型」的实验都读取这组权重，数值为均值 ± 种子间标准差。不同测试范围（固定留出集、全部未见零件、Thingi10K、重复随机留出）的数字不应拼接成同一个「最终准确率」。
- 不可达为 F1 正类；「点池」合并全部测试点计算，「零件等权」先逐件计算再平均。

## 局限

- **代理，不是认证**：oracle 是几何可达性代理（语义 C），不是物理或工艺认证；只计零件本体遮挡，得到的是遮挡下界（D-002）。
- **标签噪声**：真实标签的差分 robust 不一致 0.63%，分辨率 48 与 96 的一致率 97.28%（约 2.7% 的点会随分辨率翻转）。已量化（D-025），不为零。
- **类别不平衡**：Fusion 82% 的零件全部可达，只有 18% 是两类件（1,553 / 8,590）；不可达是稀有类（逐件比例均值 5.1%，点池 7.5%）。训练只用两类件，全分布筛查补上全可达件。
- **固定留出集偏乐观**：80 件留出集上的 F1 高于全部未见两类件（0.862）与 Thingi10K（0.848）；在 Thingi10K 上（含水密子集）主协议网络与 16 方向粗判定相当，训练零件扩大到 1,393 件后回升到 0.891。
- **D-028 口径**：缠绕安全外移的三态处理丢弃了 11,573 个法向翻转的伪下朝面点（Fusion，两类件 1621 → 1553）和 4,321 个 Thingi 点（两类件 149 → 137）。
- **数据代表性**：Fusion 以棱柱几何为主、没有自由曲面；8625 个设计中成功物化 8590 件。
- **跨来源子采样**：Thingi 每件最多 400 个接触点、面数不超过 80000（D-022），跨来源指标是子采样下的估计。
- **效率结论的范围**：精度–耗时的耗时含 Python 实现、硬件与机器负载的影响，只说明量级；两级判定器的耗时随网格面数增长。以工具半径为条件的网络属于后续工作（见 [研发路线](研发路线.md)）。
