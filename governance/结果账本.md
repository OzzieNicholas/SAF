# 结果账本

「假设 / 实验 → 指标 → 数值 → 样本 → 复现命令」的唯一出处，权威数字以此为准。数值由 `experiments/` 下的复现脚本产出，运行记录保存在 `artifacts/runs/<实验名>/result.json`；论文引用的数字另由 `paper/manuscript/numeric_claims.yaml` 与这些结果逐条核对。

- 假设编号 H1–H5 的含义见 [研究背景与设计](../docs/研究背景与设计.md) §6.1；其余实验直接用名称。
- 冻结口径见 D-021（128 个全局方向等）。本表全部数字使用 D-028 的网格前端口径、128 方向的程序化数据和 D-020 细化口径的方向标签。
- 命令在仓库根目录、已激活 `saf` 环境下运行；数据位置见 `configs/paths.yaml`。全部实验按规范参数一次重跑：`python tools/reproduce_experiments.py`（`--list` 列出，`--only 名称,名称` 选跑）。
- 带 GPU 训练的实验在同一配置下有小幅运行间波动（例如表 5 的形状条件 surrogate 与回归门各自独立训练，点池 F1 相差约 0.014），下表只记录最近一次完整重跑的值，不同实验的数字不应拼接成同一个「最终准确率」。

## 局限

- **代理，不是认证**：oracle 是几何可达性代理（语义 C），不是物理或工艺认证；只计零件本体遮挡，得到的是遮挡下界（D-002）。
- **标签噪声**：真实标签的差分 robust 不一致 0.63%，分辨率 48 与 96 的一致率 97.28%（约 2.7% 的点会随分辨率翻转）。已量化（D-025），不为零。
- **类别不平衡**：Fusion 82% 的零件全部可达，只有 18% 是两类件（1553 / 8590）；不可达是稀有类（逐件比例均值 5.1%，点池 35,210 / 467,411 = 7.5%）。训练与评测只用两类件。
- **H1 的面积口径**：「支撑面积」是下朝面计数代理（面积均匀采样未实现）。真三角面积对照的 ρ（0.124 / −0.126）绝对值小于计数代理的 0.264 / −0.221，所以「面积弱预测可达」不是代理造成的假象。面积加权的指标属于未来工作。
- **D-028 口径**：缠绕安全外移的三态处理丢弃了 11,573 个法向翻转的伪下朝面点（Fusion，两类件 1621 → 1553）和 4,321 个 Thingi 点（两类件 149 → 137）。
- **数据代表性**：Fusion 以棱柱几何为主、没有自由曲面；8625 个设计中成功物化 8590 件。
- **跨域子采样**：Thingi 每件最多 400 个接触点、面数不超过 80000（D-022），跨域指标是子采样下的无偏估计。
- **方向级场口径**：方向标签使用 D-020 边界带精确细化口径并已签收（`occupancy_fallback` = 0，即全部 500 件的占据栅格逐比特校验通过，D-024）。
- **效率结论的范围**：约 118× 只是训练后条件扫掠摊销的量级示意；「神经比逐点几何快」本身不是新发现，且比值含实现因素（oracle 侧为逐点 Python 循环）。半径扫描和工具条件插值属于未来工作（见 [研究背景与设计](../docs/研究背景与设计.md)）。
